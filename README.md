## 🛡️ Spring Security : Custom Login & Authentication Flow
Ce projet démontre l'implémentation d'un système d'authentification personnalisé sous Spring Boot 3 / Jakarta EE, en remplaçant le formulaire par défaut de Spring Security par une interface utilisateur sur mesure.


### 🎯 Objectifs Pédagogiques
- Personnalisation : Intégration d'un formulaire HTML/Thymeleaf.

-  Contrôle du flux : Gestion des redirections spécifiques aux rôles.

-  Sécurité : Configuration du SecurityFilterChain et gestion du Logout.

-  UX : Affichage dynamique des messages d'erreurs d'authentification

### 🛠️ Technologies Utilisées
- JDK 17+ 

- Spring Boot & Spring Security

- Thymeleaf

- Maven
